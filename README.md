# Data Science Digital Library (DS-Lab)

A digital learning platform and library for Data Science students at Mohan Babu University (MBU).

## 🚀 Features

- **5 Core Modules**: Structured syllabus from Python foundations to advanced data analysis.
- **6 Lab Experiments**: Step-by-step experiment guides with code snippets, algorithms, and documentation.
- **Essential Tools**: Curated list of libraries and environments (NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn, Jupyter).
- **Resources & Reference Materials**: Cheatsheets, textbooks, and documentation links.
- **Student Projects**: Real-world sample projects and case studies.

## 📁 Project Structure

```text
├── index.html       # Main webpage structure
├── style.css        # Responsive styling and slide layouts
├── script.js        # Interactive modules, modal viewer, and dynamic logic
├── mbu-logo.png     # University logo
├── photo.png        # Profile display
└── pdfs/            # PDF lab manuals and experiment documents
```

## 💻 Getting Started

Simply open `index.html` in any modern web browser or run a local web server:

```bash
# Using Python
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
