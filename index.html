Quick reference

Pandas cheatsheet

The functions you use in the labs, grouped by topic. Copy a snippet and paste it into the interactive editor inside any experiment.

MultiIndex · Exp 1, 2, 4
import pandas as pd

idx = pd.MultiIndex.from_tuples(
    [("CSE", "A"), ("CSE", "B"), ("ECE", "A"), ("ECE", "B")],
    names=["dept", "branch"])
s = pd.Series([120, 95, 110, 80], index=idx)

s["CSE"]            # every branch of CSE
s.loc[:, "A"]       # branch A in every dept
df = s.unstack()    # inner level becomes columns
df.stack()          # and back to a Series
Missing data, outliers, text · Exp 3
df.isna().sum()                      # missing values per column
df.dropna()                          # drop rows containing NaN
df.fillna({"marks": df["marks"].mean()})

df["grade"].map({"A": 4, "B": 3, "C": 2})

q1, q3 = df["marks"].quantile([0.25, 0.75])
iqr = q3 - q1
mask = (df["marks"] < q1 - 1.5 * iqr) | (df["marks"] > q3 + 1.5 * iqr)
df[mask]                             # outliers (IQR rule)

df["name"].str.split(r"\s+", expand=True)   # split text with regex
Joins & combining · Exp 4
a = pd.DataFrame({"id": [1, 2, 3], "name": ["Asha", "Ravi", "Meena"]})
b = pd.DataFrame({"id": [2, 3, 4], "marks": [78, 91, 66]})

pd.merge(a, b, on="id", how="outer")   # keep every id from both

x = pd.Series([1, None, 3])
y = pd.Series([9, 8, 7])
x.combine_first(y)                     # fill gaps in x using y
Matplotlib & Seaborn · Exp 5
import matplotlib.pyplot as plt
import seaborn as sns

iris = sns.load_dataset("iris")
iris.describe()                        # statistical summary

fig, ax = plt.subplots(1, 3, figsize=(14, 4))
ax[0].plot(iris["sepal_length"])                              # line
ax[1].scatter(iris["sepal_length"], iris["petal_length"])     # scatter
ax[2].hist(iris["petal_width"], bins=15)                      # histogram
plt.show()
Dates, zones, periods · Exp 6
rng = pd.date_range("2024-01-01", periods=6, freq="D")
ts = pd.Series(range(6), index=rng)

ts_utc = ts.tz_localize("UTC")
ts_utc.tz_convert("Asia/Kolkata")      # convert to Indian Standard Time

p = pd.Period("2024-01", freq="M")
p + 1                                  # the next month

ts.resample("W").sum()                 # weekly totals

Help

Questions

Quick answers about how the library and its live Python experiments work.

Do I need to install Python?

No. The experiments run Python in your browser using Pyodide (Python compiled to WebAssembly). The runtime is downloaded the first time, so the first run can take a few seconds.

What do the colours on the Python status badge mean?

Orange means the runtime is still loading, green means it is ready, blue means code is running, and grey means it is offline.

Can I write my own code?

Yes. Open an experiment and press 💻 Editor for a free-form Python editor. Variables stay alive between runs until you press ↺ Reset.

How do I read a module?

Click a module card to open it in the built-in PDF reader. You can also load your own copy with the Open PDF from computer button.

Does it work offline?

The pages themselves do, but the Python runtime is loaded from a CDN, so you need an internet connection to run experiments.

Can I switch to dark mode?

Use the round button at the bottom-left corner of the page. It remembers your choice next time.
